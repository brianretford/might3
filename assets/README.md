# Assets

Place your app icons, images, and other assets here.

## Icons

- App icon for macOS: 1024x1024px PNG
- App icon for iOS: Multiple sizes via Xcode Asset Catalog

## Fonts

If you want to use custom fonts (like SF Pro), place the font files in the `fonts/` directory and ensure they're referenced in `pubspec.yaml`.

Note: SF Pro is Apple's system font and may require a license for distribution.
